# 말랑 스튜디오 · Malang 3D

49가지 말랑이의 고유 물성은 그대로, 손끝으로 누르고 늘리고 돌려보는 3D 젤리 놀이터.

**[바로 체험하기](https://nam5an.github.io/malang-3d/)**

![말랑 스튜디오](docs/preview.png)

기반 프로젝트: [NAM5AN/malang](https://github.com/NAM5AN/malang), 커밋 `3f509514c7f9f7f81b9243626fdf0f87ddf50e85`. 원본 저장소와 별도로 개발하며 기존 이력을 유지합니다.

## 달라진 점

- Three.js의 실제 입체 메시, 조명, 굴절, 코팅 광택, 입체 무대와 그림자.
- 부드러운 눌림, 늘어남, 복원. 솜·스퀴시·점토·자석·탱탱볼은 원본 탄성 및 형태기억 설정을 따릅니다.
- 하트·클로버·생쥐의 고유 실루엣, 해파리의 발과 얼굴, 비즈·기포·은하·오로라·글리터.
- 다른 개발자의 실제 왁뿌볼 코드를 연구한 표면 분할 방식. 누른 곳에 금이 생기고, 두께가 있는 조각이 떨어져 속살이 드러납니다. 코팅 강도, 필요 타격 횟수, 조각 크기와 다층 왁스도 유지합니다. [참고 코드와 구현 설명](docs/WAX_REFERENCES.md).
- 49종 검색 및 무료 체험, 반응형 화면, 두 손가락 조작, 시점 회전, 음소거와 화질 선택.
- 기존 가방·뽑기·마일리지·상점·도감·꾸미기·이름 변경·분해 기능 유지.

## 실행

Node.js 22.12 이상을 권장합니다.

```sh
npm ci
npm run dev
```

터미널에 표시되는 주소를 여세요. HTML 파일을 직접 더블클릭해서 실행하지 마세요.

```sh
npm test
npm run build
npm run preview
```

`dist/`를 정적 웹 서버에 올리면 됩니다. 상대 경로 빌드라 GitHub Pages의 하위 경로에서도 실행됩니다. `main`에 변경사항을 올리면 GitHub Actions가 검사·빌드 후 Pages에 배포합니다.

## 조작

| 조작 | 동작 |
| --- | --- |
| 만지기에서 누르기 / 드래그 | 표면 누르기 / 가장자리 늘리기 |
| 같은 왁스 부위를 반복해서 누르거나 길게 누르기 | 금 발생 → 껍질 조각 분리 |
| 바사삭 리얼 왁뿌볼의 가장자리 당기기 | 단단한 껍질을 한꺼번에 깨기 |
| 두 손가락 | 양쪽을 동시에 잡기 |
| 둘러보기에서 드래그 / 휠·핀치 | 회전 / 확대·축소 |
| Space / R / V / 방향키 | 출렁임 / 다시 꺼내기 / 모드 전환 / 시점 회전 |

체험용 말랑이는 인벤토리에 추가되지 않습니다. 가방이나 수집 메뉴를 열면 마지막 보유 말랑이로 돌아옵니다. 3D 저장은 `malang3d_save`를 사용하며, 원본의 `slime_gacha_save`를 덮어쓰지 않습니다. 서로 다른 사이트의 저장 데이터는 자동 이전되지 않습니다.

## 구조와 범위

`public/legacy/data.js`의 49종 및 재료 데이터는 원본과 동일합니다. 기존 2D 윤곽 스프링을 60 Hz로 실행하고, 닫힌 입체 몸체와 표면 눌림 스프링에 연결합니다. 즉, 기존 게임의 손맛을 옮긴 하이브리드 시뮬레이션입니다. 유체 해석이나 전체 부피를 수치적으로 보존하는 FEM 연체 시뮬레이션은 아닙니다. 파편은 중력·회전·바닥 반동을 계산하며 파편끼리의 충돌은 생략합니다.

| 파일 | 역할 |
| --- | --- |
| `public/legacy/` | 원본 데이터, 게임 상태, 물성, 효과음, 2D 대체 화면 |
| `src/soft-body.js` | 입체 몸체, 깊이, 눌림 및 형태기억 |
| `src/wax-shell.js` | 구면 표면 분할, 파단면, 왁스 파편 |
| `src/materials.js` | 원본 특성을 3D 재질로 변환 |
| `src/main.js` | 3D 장면, 조작, 기존 게임과 연결 |
| `tests/physics.test.js` | 데이터 보존과 형상·복원·왁스 회귀 검사 |

WebGL 2가 필요합니다. 사용할 수 없으면 원본 2D 렌더러로 실행하며 이를 화면에 알립니다. 모델·텍스처를 외부 서버에서 받아오지 않습니다. 기기별 그래픽 성능 차이가 있으므로 기본 화질의 픽셀 비율을 1.5로 제한합니다.
