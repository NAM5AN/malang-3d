# 3D 연체 시뮬레이션

## 재작성 범위

기존의 2D 윤곽 스프링, 윤곽 부풀리기, 화면 좌표 변형, 입력 연결, 상태 저장, HTML/CSS를 사용하지 않습니다. `public/legacy/`와 이전 `src/main.js`, `soft-body.js`, `wax-shell.js` 등은 삭제했습니다. 원작에서 가져온 것은 캐릭터의 이름·색·고유 촉감·수집 및 꾸미기 기획입니다. Three.js와 Vite, 배포 설정은 범용 도구로 계속 사용합니다.

## 볼륨과 탄성

정육면체 격자를 둥근 체적으로 사상하여 216개 입자를 만들고, 각 격자 셀을 여섯 사면체로 나눕니다. 총 750개 사면체가 물체의 **내부 전체**를 채웁니다. 초기 체적의 부호를 맞춘 뒤 모든 사면체의 부피를 양수로 유지합니다.

60 Hz 고정 시간 간격, 프레임당 6회 하위 단계, 각 단계에서 3회의 제약 반복을 사용합니다.

- 탄성: 사면체 간선 길이와 재질별 compliance.
- 부피: `V = dot(b-a, cross(c-a,d-a))/6`. 작은 사면체의 부피 제약에는 유연함을 주고, 전체 사면체 합을 보존하는 별도 제약을 풀어 눌린 속살이 옆으로 퍼질 수 있게 합니다.
- XPBD: `Δλ = (-C - α̃λ)/(Σw|∇C|² + α̃)`, `α̃ = compliance / dt²`.
- 접촉: 바닥과 시간 간격에 맞춘 마찰. 바닥 입자를 특정 좌표에 붙잡거나 물체를 화면 중앙으로 끌어당기는 힘은 사용하지 않습니다. 들어 올리면 밑부분도 따라옵니다.
- 손가락: 접점 주위의 넓은 입자 영역을 가중치로 연결합니다. 가중치를 두 번 적용해 손의 이동이 지나치게 약해지지 않도록 조정했으며, 최초 누르는 깊이는 100ms 동안 증가시켜 얇은 모양도 걸리지 않게 합니다.
- 갑작스러운 입력: 잡기 목표의 속도 및 도달 범위를 제한하고, 간선의 과도한 신장을 제한합니다.
- 체적 반전: 작은 사면체가 초기 부피의 24% 아래로 압축되면 국소 장벽 제약으로 밀어내고, 12% 아래로 내려가려는 단계는 되돌려 더 작은 이동으로 검사합니다.

## 매끈한 표면

5,402개 정점의 닫힌 표면은 물리 입자보다 촘촘합니다. 정지 상태의 **3차원 공간**에서 정규화한 양수 C2 방사 기저 가중치 `(1-r)^4(4r+1)`로 내부 변위를 보간합니다. 큐브 면 경계에서 보간 방향이 달라져 생기는 이음새를 피합니다. 정점당 가중치의 합은 1이며, 음의 가중치에 의한 돌출을 만들지 않습니다. 표면 법선은 변형 후 다시 계산합니다.

## 재질의 차이

젤리·액상·고무·탱탱볼은 탄성 및 감쇠가 다릅니다. 스퀴시는 일시적인 정지 변형을 저장했다가 수초에 걸쳐 되돌리는 점탄성 모델입니다. 점토는 간선의 정지 길이를 영구적으로 변화시키는 소성 모델입니다. 전체 사면체 부피 제약은 모두 유지됩니다.

왁스는 별도의 껍질이며, 몇 조각이 깨져 구멍이 열리면 속살이 유연해지도록 경도를 조절합니다. 파괴되는 것은 코팅이고 속살 사면체는 연결된 상태를 유지합니다. 자성 퍼티는 마우스가 가까워질 때 넓은 인력 손잡이를 만듭니다.

- [12 Soft Body Skinning](https://matthias-research.github.io/pages/tenMinutePhysics/12-softBodySkinning.html): 저해상도 물리와 고해상도 시각 표면 분리의 참고.

## 범위

이 구현은 실제 체적 요소를 계산하는 실시간 3D 연체입니다. 물질을 측정해 맞춘 공학용 FEM이나 유체 솔버는 아닙니다. 표면의 보간 체적은 사면체 체적과 정확히 일치하지 않으며, 문서의 부피 오차 수치는 **시뮬레이션 사면체 전체**에 대한 값입니다. 코어의 찢김과 자기 충돌, 파편끼리의 충돌은 계산하지 않습니다. 이를 감안해 잡기 범위와 변형률을 제한했습니다. 고유 모양의 끝부분은 원래 디자인을 유지합니다.
