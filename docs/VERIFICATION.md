# 검증 기록

검증일: 2026-09-07. Windows의 Chromium, 로컬 개발 서버 및 정적 빌드를 사용했습니다.

## 자동 회귀 검사 (`npm test`)

1. 원본 49종 및 재료 데이터의 SHA-256 일치 (줄바꿈 형식만 정규화).
2. 전체 49종에 대해 유효한 3D 좌표, 양의 부피, 바깥쪽 면 방향 확인.
3. 젤리 눌림은 복원되고 점토의 눌린 모양은 유지됨.
4. 늘어날 때 유리 재질의 투과율 증가, 솜·금속은 불투명 유지.
5. 두꺼운 왁스의 3회 타격, 동일 제스처 중복 방지, 실제 외피 삭제 및 단면·파편 생성, 초기화/자원 정리.
6. 앞면과 뒷면 왁스의 독립적인 손상.

## 브라우저 통합 검사

- 49종 모두 순차 선택해 렌더링, 유한한 메시 좌표, 실행 오류 없음 확인.
- 모든 체험 선택 후에도 보유 목록과 저장된 선택은 유지됨.
- 기존 뽑기 보상 → 재료 구매 → 꾸미기 미리보기 → 완성 → 3D 비즈 표시.
- 사용자 조합의 두 겹 왁스에서 첫 겹 파손 → 초코색 다음 겹 → 최종 속살 노출.
- 실제 CDP 터치 입력으로 두 손가락 동시 잡기 및 늘리기, 터치 취소 시 모든 제약 해제.
- 터치 드래그로 카메라 회전 확인.
- 두꺼운 왁스를 길게 누르면 금이 간 뒤 분리됨.
- 마우스로 잡아 늘리기, 검색/선택, 초기화, 가방, 도움말 조작.
- 데스크톱 1440×900, 모바일 390×844에서 화면 배치 및 가로 넘침 없음 확인.

## 확인 범위

`npm run build` 성공. 모바일 터치는 Chromium의 실제 터치 이벤트 에뮬레이션으로 검사했으며 iPhone/Android 실물 기기 성능까지 측정한 것은 아닙니다. WebGL 드라이버에 따라 반사·그림자와 프레임 속도는 달라질 수 있습니다.
