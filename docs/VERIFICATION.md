# v2 검증 기록

## v2.1 촉감 회귀 검사

`tests/feel.test.js`는 물체가 멈춘 채 부피만 보존하는 상태도 실패하도록 실제 표면의 움직임을 검사합니다.

- 위에서 누르면 젤리 높이는 약 29% 낮아지고, 바닥을 향한 폭×깊이는 약 27% 넓어집니다.
- 한 곳을 1.8단위 들어 올리면 밑면도 약 0.36단위 상승합니다. 특정 바닥 좌표에 고정되지 않습니다.
- 놓은 뒤 0.3초 동안 중심 이동을 제외한 표면 변화량은 약 0.23이며, 마지막 0.1초에도 약 0.084의 변화가 남습니다.
- 7개 고유 모양을 보통 속도로 당길 때 표면이 손을 따라 움직이고, 반복적인 안전 복구로 멈추는 횟수는 0회였습니다.
- 기존 물리·왁스·저장 검사는 함께 유지합니다. 아래 수치 기록은 초기 v2.0의 검증 결과입니다.

총 11개 테스트가 통과했습니다. 브라우저에서도 49종을 각각 눌렀고, 모바일 두 손가락 늘리기·놓기·취소에서 반전과 반복 안전 복구는 모두 0회였습니다. 기본 젤리의 90프레임 관찰은 해당 데스크톱 환경에서 약 57 FPS였습니다.

## v2.0 초기 검증

2026-09-07, Windows / Node.js 26.7.0 / Chromium 자동화 환경에서 실행했습니다.

## 계산 및 상태 검사

`npm test`의 7개 검사를 통과했습니다.

- 49종의 정의, 7개 고유 모양: 초기 사면체 체적이 모두 양수이고 중력 아래에서도 안정적입니다.
- 11개 촉감: 넓게 잡아 당기고 놓는 시험에서 사면체 반전 0, 유한한 좌표, 전체 체적 변화 최대 **0.692%**.
- 7개 모양을 두 방향으로 당기고 매우 큰 입력 좌표로 이동하는 시험: 목표 이동 제한, 체적 보호, 해제 및 복원 통과.
- 고무와 스퀴시의 복원 시간 차이, 점토의 영구 변형을 수치로 확인했습니다. 스퀴시의 변형은 서서히 줄고 점토는 남습니다.
- 왁스: 얇은 코팅 1회 / 두꺼운 코팅 3회, 실제 표면 삼각형 감소, 조각의 모든 모서리에 두 면이 연결되어 두께 있는 닫힌 조각임을 확인했습니다.
- 표면 보간: 양수 가중치, 합 1, 전체 평행 이동을 정확히 따르는지 검사했습니다.
- 수집: 저장 후 복구, 중복 레벨, 뽑기 비용, 꾸미기 재료 차감, 잔액 부족 처리.

체적 수치는 화면 픽셀이 아니라 **750개 물리 사면체**의 합입니다. 시험 범위를 넘어선 모든 변형을 보장하는 수치는 아닙니다.

## 브라우저

- 데스크톱 1440×900, 모바일 390×844에서 페이지·캔버스·목록·대화상자가 정상 표시됐습니다.
- 49종을 각각 선택하고 눌러서 렌더링 및 물리 상태를 확인했습니다. 이 검사에서 최대 체적 변화는 약 0.688%였습니다.
- 기본 물젤리를 90프레임 관찰했을 때 해당 환경에서 약 57 FPS였습니다. 기기별 성능은 다릅니다.
- 실제 CDP 터치 이벤트로 두 손가락을 동시에 잡아 양쪽으로 늘리고, 놓고, 취소했습니다. 손잡이 개수 2 → 0, 반전 0. 늘리는 중 체적 변화 약 0.244%, 놓은 후 약 0.005%.
- 뽑기 → 새 친구 선택, 상점 구매, 재료 두 개를 사용한 꾸미기 → 새로고침 후 이름·재료·선택 복원을 확인했습니다.
- 도감 검색과 미보유 친구 체험, 모바일 보관함 열기/닫기, 시점 복원, 코팅 파괴, 해파리·하트·클로버 표시를 확인했습니다.
- 페이지 오류 및 가로 넘침을 발견하지 않았습니다.

원작의 2D 코드를 제거한 별도 구현입니다. 이전 `malang3d_save`와 별개의 새 저장 형식을 사용합니다.
